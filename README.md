# 💬 Realtime Chat Application (Frontend)

Dự án **AppChat** là ứng dụng nhắn tin thời gian thực (Realtime Chat) được xây dựng với ReactJS. Ứng dụng kết nối với WebSocket Server có sẵn để cung cấp trải nghiệm gửi và nhận tin nhắn tức thì.

---

## 🛠️ Công nghệ sử dụng (Tech Stack)

Dự án được xây dựng dựa trên các thư viện và công nghệ nổi bật sau:

* **Core:** ReactJS, Vite (hoặc CRA).
* **State Management:** Redux Toolkit, Redux Persist.
* **Realtime Connection:** React Use Websocket.
* **UI/UX:** TailwindCSS, Chakra UI, Framer Motion, Lucide React (Icons).
* **Features:** Emoji Picker React.

---

## 📋 Yêu cầu tiên quyết (Prerequisites)

Trước khi cài đặt, hãy đảm bảo máy tính của bạn đã cài đặt:
* [Node.js](https://nodejs.org/) (Khuyến nghị phiên bản LTS mới nhất)
* [Git](https://git-scm.com/)

---

## 🚀 Hướng dẫn cài đặt (Installation)

Để chạy dự án này trên máy cục bộ, vui lòng thực hiện lần lượt các bước sau:

### **Bước 1: Clone dự án**
Tải mã nguồn từ GitHub về máy tính của bạn:

```bash
git clone [https://github.com/VoPhong25/FrontEnd-Nhom80-AppChat.git](https://github.com/VoPhong25/FrontEnd-Nhom80-AppChat.git)
```

**Bước 2: Cài đặt thư viện (Dependencies)**
Các thư viện cần thiết khi chạy pj:
```bash
npm install react-router-dom
npm install @reduxjs/toolkit react-redux redux-persist react-use-websocket
npm install -D tailwindcss@3 postcss autoprefixer
npm install @chakra-ui/react@2 @emotion/react @emotion/styled framer-motion
npm install lucide-react
npm install emoji-picker-react
```

**Bước 3: Chạy dự án (Running the App)**
```bash
npm run dev
```
